# Windows 11 虚拟桌面任务栏增强工具 (Virtual Desktop Taskbar Enhancer)

这是一个基于 AutoHotkey (AHK) 开发的 Windows 11 虚拟桌面增强脚本。  
工具专为提升多桌面切换效率而设计，通过 **“任务栏悬停免点击”** 的交互逻辑，实现极速的桌面切换、创建、删除、重命名以及直观的屏幕 HUD 状态提示。  
同时新增 **首字母跳转**、**快速往返** 等快捷操作，让多桌面管理如行云流水。

---

## 🚀 核心功能特性

### 1. 全局任务栏免点击交互
> **触发前提**：鼠标光标必须位于**屏幕下方的任务栏区域内**（无需进行任何点击）。  
> *（同时也支持屏幕顶部 10% 区域触发，方便触屏或 Dock 用户）*

| 快捷键 / 动作 | 功能说明 | 边界逻辑 |
| :--- | :--- | :--- |
| `Ctrl + 1 ~ 9` | 快速切换到第 1 到 9 个虚拟桌面 | - |
| `Ctrl + Tab` | 切换到**下一个**虚拟桌面 | 末尾不循环 |
| `Ctrl + Shift + Tab` | 切换到**上一个**虚拟桌面 | 开头不循环 |
| `鼠标滚轮向上` | 切换到**上一个**虚拟桌面 | 开头不循环 |
| `鼠标滚轮向下` | 切换到**下一个**虚拟桌面 | 末尾不循环 |
| `Alt + Tab` | 切换回**上一个**访问的桌面（快速往返） | 在最近两个桌面间切换 |
| `Ctrl + A ~ Z` | 按当前桌面**名称首字母**跳转（不区分大小写） | 若多个同名首字母，循环切换 |
| `F2` | 弹出输入框，**重命名**当前桌面 | 自动持久化 |
| `Ctrl + Shift + N` | **创建**一个新的虚拟桌面 | 自动切换至新桌面 |
| `Ctrl + Delete` | **删除**当前虚拟桌面 | 自动回退至上一个桌面 |

### 2. 智能化辅助功能
- **🖥️ 桌面切换 HUD 提示**：切换桌面时，屏幕中央会短暂弹出半透明的文本提示（显示如 ` 虚拟机` 或 ` 浏览器`），停留 1~2 秒后自动淡出，不干扰视线。
- **🎨 系统托盘图标（Tray）**：右下角托盘图标实时显示当前桌面编号。鼠标悬停时展示完整桌面名称；右键点击可呼出菜单随时退出程序。
- **💾 桌面名称持久化**：通过 `F2` 修改的桌面名称将即时保存到本地配置文件中（如 `config.ini`）。下次启动电脑或重启脚本时，自动读取并恢复个性化名称。
- **🔁 首字母智能跳转**：按下 `Ctrl + 字母` 即可跳转到以该字母开头的桌面。若有多个，反复按同一键循环切换；若无匹配，则无操作。

## ⚙️ 强力推荐：Windows 系统高亮污染净化设置
> **重要配合**：Windows 11 默认会将其他虚拟桌面的软件动态和红点穿透到当前桌面，导致任务栏图标频繁出现“假高亮/假闪烁”，极度干扰视线。  
> 为了配合本脚本达到最完美的“纯净多桌面独立体验”，**强烈建议**在你的 Windows 英文系统中手动关闭以下系统设置：

### 1. 关闭跨桌面通知闪烁与红点
1. 按下 **`Win + I`** 打开 **Settings**（设置）。
2. 依次点击：**Personalization**（个性化） ➡️ **Taskbar**（任务栏）。
3. 滚动到页面底部，点击展开 **Taskbar behaviors**（任务栏行为）。
4. **取消勾选（不要选）** 以下两项：
   * ⬜ **Show flashing on taskbar apps** —— *（彻底禁止其他桌面的软件通过变橙色/闪烁来干扰当前视线）*
   * ⬜ **Show badges on taskbar apps** —— *（防止其他桌面的软件因为新消息在当前图标上顶出高亮红点）*

### 2. 开启任务栏虚拟桌面完全隔离
1. 回到 **Settings**（设置）主页，点击 **System**（系统） ➡️ **Multitasking**（多任务）。
2. 点击展开 **Desktops**（桌面）部分。
3. 将 **"Show all open windows on the taskbar"**（在任务栏上显示所有打开的窗口）这一项下拉菜单修改为：
   * 🎯 **Only on the desktop I'm using** —— *（让当前任务栏只保持当前桌面干净的软件图标，不被其他桌面污染）*

## 📦 前置依赖与安装

- 本脚本需要 **AutoHotkey v2.0** 运行环境。
- 必须将 `VirtualDesktopAccessor.dll` 置于与脚本相同的目录下（[下载地址](https://github.com/Ciantic/VirtualDesktopAccessor)）。
- 首次运行时，脚本会自动请求管理员权限（用于操作虚拟桌面 API）。

---

## 🧰 使用须知

- 所有快捷键**仅在鼠标位于任务栏或屏幕顶部 10% 区域时生效**，避免干扰其他应用程序的快捷键。
- 若桌面总数少于 9 个，`Ctrl + 数字` 跳转至存在的桌面，超出则无反应。
- 删除桌面时，若当前桌面为最后一个，则自动回退至前一个桌面。
- 重命名支持中英文及特殊字符，名称长度不限（显示时自动截断至 16 字符）。

---

## 🛠️ 自定义与扩展

- 您可修改脚本开头的 `maxLength` 变量调整 HUD 显示字符数。
- 可调整 `FadeOpacity` 步进值（30/20）改变淡入淡出速度。
- 所有桌面名称储存在 `config.ini` 中（首次重命名后生成），可手动编辑。
